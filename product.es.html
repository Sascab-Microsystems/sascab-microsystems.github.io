Producto · Núcleo de IP de compresión

BioRLE-1

IP de compresión de señales biomédicas para monitores cardíacos. Núcleo del algoritmo abierto bajo Apache 2.0, capa de integración licenciada, validado y listo para tape-out.

Categoría: Núcleo de IP de compresión Dominio: ECG / bioseñales Estado: Listo para tape-out

Qué es

Un bloque de compresión dedicado, entre la adquisición y todo lo que viene después.

BioRLE-1 toma la salida digitalizada del front-end analógico y emite una trama comprimida antes de que el dato llegue a la memoria o a la radio. Todo lo que sigue — almacenamiento, buffers, transmisión, ingesta en la nube — maneja una carga menor.

Al ser un bloque de hardware y no firmware, la compresión ocurre sin gastar ciclos del MCU anfitrión, y el costo energético es acotado y predecible en lugar de depender de qué más esté haciendo el procesador.

Dónde encaja: AFE → ADC → BioRLE-1 → memoria / MCU / radio. Es deliberadamente estrecho: una sola función, resuelta en una cantidad de lógica pequeña y verificable.

Cadena de señalsimplificada
// adquisición electrodos → AFE → ADC | v [ núcleo de compresión BioRLE-1 ] | v // aguas abajo, ahora menor flash · MCU · BLE / LTE-M · nube // reconstrucción host / nube → decodificador → señal
